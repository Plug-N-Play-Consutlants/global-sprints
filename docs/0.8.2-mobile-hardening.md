# v0.8.2 mobile hardening checkpoint

Based on v0.8.1. Targets iPhone Safari and responsive layouts.

- Enforces PNPC light palette independent of iOS dark preference or host dark variables.
- Reflows forms, planning, workspace selectors, reports and content into mobile columns.
- Uses horizontally scrollable tab navigation and Kanban content instead of compressing cards.
- Improves mobile touch sizing and protects overflow for tables and ceremony previews.
- Updates manifest and diagnostic version to 0.8.2.

Validation: static package, JS syntax and responsive CSS assertions. Real iPhone Safari verification remains required.

This is not the completed v0.8 production readiness milestone. Licensing and other hardening work remain.
