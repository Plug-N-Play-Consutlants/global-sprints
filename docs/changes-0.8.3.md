# v0.8.3 — iPhone Safari and optional sprint guidance

- Detect physically narrow iOS screens even when Azure DevOps embeds the extension at desktop iframe widths; apply mobile reflow without modifying the Azure DevOps host shell.
- Improve touch targets, workspace selectors, navigation, cards, panels, and Board lane overflow.
- Add optional Use Guide in existing New Sprint dialog and two independent post-create navigation prompts for backlog work and ceremonies.
- Preserve existing Demo, reports, Outlook and production data workflows.

- Licensing, Product Command, and comprehensive security/concurrency hardening remain open v0.8 release gates.
